# C++ Singly Linked List Manager

A robust, menu-driven command-line application implemented in C++ to demonstrate fundamental data structure operations using a singly linked list.

## 🚀 Features

- **File Loading:** Read and ingest integer data directly from an external text file (`lista.txt`).
- **Sequential Traversal:** Print all elements currently stored in the linked list.
- **Value Search:** Locate the first occurrence of a specific value and return its 0-based index.
- **Node Deletion:** Safely remove nodes by their index (with boundary and head-pointer handling).
- **List Mirroring:** Reverse the direction of the linked list in-place.
- **Memory Safety:** Cleanly release all dynamically allocated memory upon exit to prevent memory leaks.
